# 投资信息分析系统 (Investment Information Analysis System)

## 项目简介

投资信息分析系统是一个基于 Java + Spring Boot 的智能投资信息采集与分析平台，通过抓取多源财经资讯，利用自然语言处理技术分析投资机会。

## 技术栈

- Java 17
- Spring Boot 3.x
- Maven 3.9.12
- MySQL / PostgreSQL
- Redis
- Elasticsearch (可选)

## 核心功能

- 📰 多源资讯抓取
- 🔍 智能信息分析
- 💡 投资机会识别
- 📊 数据可视化展示
- 🔔 实时预警通知

## 快速开始

```bash
# 克隆项目
git clone https://github.com/zncepup/info-analyse.git

# 进入项目目录
cd info-analyse

# 编译项目
mvn clean install

# 运行项目
mvn spring-boot:run
```
